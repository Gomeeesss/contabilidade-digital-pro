Opção 2: Sincronização Automática em Tempo Real (Google Drive API v3)

Quando configurado com um Google OAuth Client ID, cada aluno clica em "Conectar Drive", autoriza sua conta Google e o sistema cria automaticamente a pasta "Contabilidade Digital Pro" salvando o arquivo Contabilidade_<login>.json a cada lançamento.

Tutorial rápido: Como obter um Google Client ID gratuito (2 minutos)
  1. Acesse console.cloud.google.com e crie um novo projeto (ex.: Contabilidade-Aula).
  2. No menu lateral, vá em APIs e Serviços > Biblioteca, pesquise por Google Drive API e clique em Ativar.
  3. Vá em Tela de permissão OAuth, escolha tipo Externo, preencha o nome do app e salve (em Usuários de teste ou status Em produção).
  4. Vá em Credenciais > + Criar Credenciais > ID do cliente OAuth, selecione Aplicativo da Web.
  5. Em Origens JavaScript autorizadas, adicione o endereço onde este sistema está hospedado (ex.: https://seu-site.netlify.app).
  6. Copie o ID do cliente gerado e cole no campo acima (ou na constante DEFAULT_GOOGLE_CLIENT_ID do arquivo HTML).
